# Kitchen mode

Open **Meals & recipes → Open Kitchen mode** on a tablet. You can bookmark
`/meals/cook` for today's planned recipe. The planned view uses the same recipe
and household ingredient amounts as the daily recipe receipt.

The method starts with one large step at a time. Use **Previous**, **Next step**,
or **Show all steps**. Tick ingredients as you prepare them. Step position and
ticks survive reloads of that recipe in the same tab; changes to the date or
recipe amounts start a new checklist. Without JavaScript the full method is
shown at once.

Use **Keep screen awake** if the button is offered. It is optional and relies
on browser and system permission. If it is unavailable, use the tablet's own
screen settings. Recipe notes keep listed allergens and the existing household
dietary checks within reach.

You can also choose another recipe allowed by your current meal settings. Opening
a recipe in Kitchen mode does not replace the planned meal or mark it eaten.
